# ITQ+ — instaladores

Este repositório guarda **somente os instaladores e pacotes de atualização** do ITQ+.
O código-fonte fica em um repositório privado.

## Instalar em um computador novo

1. Abra a [última versão](https://github.com/MasterOliver21/ITQPlus-releases/releases/latest).
2. Baixe **ITQPlusApp-win-Setup.exe** e execute.
3. Se o Windows mostrar "Windows protegeu seu computador", clique em **Mais informações → Executar assim mesmo**.
4. Abra o **ITQ+** pelo atalho. No primeiro acesso, o sistema pede para criar o usuário administrador.

## Atualizações

O ITQ+ procura versões novas sozinho ao abrir, baixa em segundo plano e instala quando for fechado.
Os dados da escola ficam em outra pasta e não são afetados.
